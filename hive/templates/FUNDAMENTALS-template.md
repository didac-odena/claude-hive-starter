## Proceso de cambio

Para modificar un documento fundamental o una invariante:
1. Kadid detecta la contradiccion y BLOQUEA
2. Se presenta al usuario con: que se quiere cambiar, por que, que impacto tiene
3. El usuario aprueba o rechaza
4. Si aprueba: se actualiza el documento fundamental Y este archivo
